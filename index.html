كيف أنشر الباك إند؟

  2. شغّل: cd backend && pip install -r requirements.txt
  3. سجّل دخول تليجرام: python auth_telegram.py
  4. شغّل السيرفر: python main.py
  5. اربطه بدومين و HTTPS وارجع حط الرابط هنا.
